# Personal Portfolio Website

A responsive personal portfolio website built with **HTML5** and **CSS3** (no JavaScript) for the HTML & CSS Practical Assessment.

## Sections
- Home – welcome heading, introduction, profile photo, Contact Me button
- About – introduction, education, interests and career goals
- Skills – six skill cards
- Projects – CampusProof and this portfolio
- Contact – form with required-field validation
- Footer – copyright and social links

## Files
- `index.html` – page structure
- `style.css` – external stylesheet (Flexbox, Grid, hover effects, media queries)
- `images/` – profile photo
- `screenshots/` – desktop and mobile screenshots
